# Divider

A `hairline` rule. Flutter: `PennyDivider`, with an optional `label` centred on the rule.

- Separate content with space first; add a divider only when space alone does not group it, such as between the sign-in methods ("or") or above an account's sign-out section.
- Never put each item of a list in its own card instead; rows sit on one surface divided by hairlines.
- The label is `small` in `text-secondary`, one short word.
